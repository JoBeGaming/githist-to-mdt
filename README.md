# githist-to-mdt

Generate a Markdown Table from a Git History.

To generate the table, clone the repository and run [`gh2mdt`](https://github.com/JoBeGaming/githist-to-mdt/blob/main/gh2mdt), with the local repository path given as an argument. Optionally the target path can be given as an additional argument, otherwise the repositories root is used, and a `result.md` file is added.

## Requirements

Python 3.6 *should* be enought. After installing python, get [pip](https://pip.pypa.io/en/stable/installation/) and run following command:

```shell
pip install -r requirements.txt
```
